## Синхронизация доступа к общим данным
Написать банк, которым одновременно пользуются несколько потоков, и проверить, что деньги в нём не теряются и не появляются из ниоткуда.
## Цель
Научиться защищать общие данные мьютексом и делать интерфейс класса таким, чтобы его можно было безопасно вызывать из нескольких потоков. Увидеть, во что обходится синхронизация.
## Постановка задачи
Реализовать класс Bank, который хранит счета и учитывает наличные в обороте. Положили деньги на счёт — наличных стало меньше, сняли — больше. При любом числе потоков банк соблюдает два правила: сумма наличных и денег на всех счетах не меняется; ни баланс, ни наличные не уходят в минус.
Поверх банка написать симуляцию экономики. Директор электростанции платит Отцу зарплату на счёт. Отец платит за электричество и даёт наличные Матери и детям. Мать и дети покупают в магазине, Продавец кладёт выручку на свой счёт и тоже платит за электричество. У каждого участника есть кошелёк с наличными; если денег не хватает, он пропускает ход.
## Требования
Банк
1.	Интерфейс — в скелете ниже, имена и сигнатуры открытых методов не меняются.
2.	Методы можно вызывать из разных потоков одновременно. Один std::mutex на весь банк, захват — через std::lock_guard.
3.	Отрицательная сумма — std::out_of_range; нет счёта или не хватает денег — BankOperationError. Если метод бросил исключение, он ничего не меняет: балансы и наличные остаются прежними.
4.	Банк считает, сколько раз вызывали его методы, в том числе неудачно. GetOperationsCount() возвращает это число (сам этот вызов не считается). Счётчик — std::atomic<unsigned long long>: тогда потоки могут увеличивать и читать его одновременно без мьютекса, и гонки не будет.
      Симуляция
5.	Командная строка: bank --mode <single|parallel> --seconds <N> [--quiet]. Аргумент --mode задаёт режим: single — все участники ходят по очереди в одном потоке, parallel — каждый участник в своём std::jthread. --seconds — сколько секунд идёт симуляция. Необязательный --quiet отключает печать действий участников («Отец дал Сыну 50»), остаётся только итог — так замеряют скорость. Пример: bank --mode parallel --seconds 10 --quiet.
6.	Программа работает N секунд или до Ctrl+C и завершается без зависаний.
7.	Снимать со счёта — через TryWithdrawMoney, а не парой GetAccountBalance + WithdrawMoney.
8.	Кошелёк — наличные на руках у участника. Кошельком тоже пользуются несколько потоков сразу: Отец в своём потоке кладёт деньги в кошелёк Сына, а Сын в это же время тратит из него в своём. Поэтому у каждого кошелька свой std::mutex. Взять деньги из кошелька — один метод, который сам проверяет, хватает ли денег, и только потом уменьшает сумму.
9.	В конце программа печатает число операций в секунду и проверяет оба правила: сумма кошельков равна GetCash(), а GetCash() плюс все балансы — начальной сумме. Проверка — после завершения всех потоков.
      Тесты
10.	Юнит-тесты класса Bank на любом фреймворке: каждая операция и каждая ошибка.
11.	Многопоточный тест. Создайте банк и один счёт, запомните наличные, баланс и GetOperationsCount(). Запустите 8 потоков: каждый 100 000 раз делает DepositMoney(счёт, 1) и сразу WithdrawMoney(счёт, 1). После join() проверьте: наличные и баланс такие же, как в начале, а счётчик операций вырос ровно на 1 600 000 (8 потоков × 100 000 × 2 операции). Иначе в банке есть гонка.
12.	Сборка через CMake: cmake -B build && cmake --build build.

```c++
       Скелет
       using AccountId = unsigned long long;
       using Money = long long;
    
    // Нет счёта или не хватает денег
    class BankOperationError : public std::runtime_error
    {
    public:
    using std::runtime_error::runtime_error;
    };
    
    class Bank
    {
    public:
    explicit Bank(Money cash);                               // cash — наличные в обороте
    
        AccountId OpenAccount();                                 // новый счёт с нулём
        Money CloseAccount(AccountId account);                   // остаток уходит в наличные
    
        void DepositMoney(AccountId account, Money amount);      // наличные -> счёт
        void WithdrawMoney(AccountId account, Money amount);     // счёт -> наличные
        bool TryWithdrawMoney(AccountId account, Money amount);  // false, если не хватает
    
        Money GetAccountBalance(AccountId account) const;
        Money GetCash() const;
        unsigned long long GetOperationsCount() const;
    
    private:
    mutable std::mutex m_mutex;  // mutable — чтобы захватывать мьютекс в const-методах
    // ...
    };
```

Обработчик Ctrl+C только записывает true в глобальный std::atomic<bool>; потоки проверяют этот флаг перед каждым ходом.
